## Project Structure
The project follows a standard Gradle Java project layout with a layered architecture.
```txt
Shippin/
├─ build.gradle
├─ settings.gradle
├─ gradlew
├─ gradlew.bat
├─ src/
│  ├─ main/
│  │  ├─ java/
│  │  │  └─ org/shippin/
│  │  │     ├─ app/
│  │  │     ├─ service/
│  │  │     ├─ util/
│  │  │     └─ ...
│  │  └─ resources/
│  └─ test/
│     └─ java/
└─ doc/
```
